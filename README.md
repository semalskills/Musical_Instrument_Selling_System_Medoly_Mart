# 🎸 MelodyMart – Web-Based Musical Instrument Store & Management System

**MelodyMart** is a full-stack e-commerce web application built using **Java (Servlets & JSP)**, **Microsoft SQL Server**, **HTML5**, and **CSS3**. It provides an online storefront for browsing and purchasing musical instruments alongside a centralized administrative dashboard for inventory, order, and catalog management.

---

## ✨ Key Features

- **Product Catalog & Advanced Search/Filtering:** Browse musical instruments with multi-criteria filtering by category, brand, price range, and real-time search.
- **Shopping Cart & Checkout:** Add instruments to the cart, apply vouchers, calculate delivery charges, and place customer orders.
- **Central Management Portal (Admin Dashboard):** Real-time overview of total sales, registered users, active suppliers, courier dispatches, and full CRUD management for products and inventory.
- **User Account & Profile Management:** Secure user registration, authentication, and profile management.

---

## 🛠️ Tech Stack

- **Backend:** Java, Jakarta/Java Servlets, JSP (JavaServer Pages)
- **Database:** Microsoft SQL Server (JDBC)
- **Frontend:** HTML5, CSS3, JavaScript
- **Server & Tools:** Apache Tomcat, IntelliJ IDEA, Git & GitHub

---

## ⚙️ How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/semalskills/Musical_Instrument_Selling_System_Medoly_Mart.git](https://github.com/semalskills/Musical_Instrument_Selling_System_Medoly_Mart.git)

   

 1.Open in IntelliJ IDEA: Import the project as a Maven/Java Web project
 
 2.Database Setup: Create a database named melodymart_db in Microsoft SQL Server and configure your JDBC connection credentials in the database utility class.

 3.Deploy on Tomcat: Configure an Apache Tomcat server in IntelliJ IDEA and run the application.

 4.Access the App: Open http://localhost:8080/ in your browser.
